# Smart Attendance System

An automated, intelligent attendance management system designed to track and record attendance efficiently using a mobile camera feed. 

## 🚀 Features

* **Mobile Camera Integration:** Stream or capture images directly from a mobile device to function as the capture unit.
* **Automated Tracking:** Seamlessly process and log attendance records in real-time.
* **Lightweight & Modular:** Built primarily in Python, making it easy to extend, integrate with databases, or deploy alongside computer vision libraries.

---
